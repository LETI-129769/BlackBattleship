## Scrum Product Backlog — Battleship

1. **Como jogador**, quero escolher um nickname, para ser identificado durante as partidas.

2. **Como jogador**, quero poder jogar sem criar uma conta, para começar a jogar rapidamente.

3. **Como jogador**, quero escolher entre jogar contra um robot, contra um adversário aleatório ou com um amigo, para decidir como pretendo jogar.

4. **Como jogador**, quero criar uma partida com um amigo e partilhar um link de convite, para que este possa entrar diretamente no jogo.

5. **Como jogador**, quero ser emparelhado automaticamente com outro jogador disponível, para poder jogar online sem precisar de convidar alguém.

6. **Como jogador**, quero jogar contra um robot, para poder jogar mesmo quando não tenho outro adversário disponível.

7. **Como jogador**, quero ter um tabuleiro de 10×10 com uma frota de cinco navios colocados aleatoriamente, para iniciar uma partida de batalha naval.

8. **Como jogador**, quero visualizar o meu tabuleiro e o tabuleiro do adversário, para acompanhar a minha frota e os resultados dos meus ataques.

9. **Como jogador**, quero disparar mísseis contra posições do tabuleiro adversário, para tentar atingir e afundar os seus navios.

10. **Como jogador**, quero receber uma indicação visual quando acerto ou falho um disparo, para conhecer o resultado de cada ataque.

11. **Como jogador**, quero poder voltar a disparar quando atinjo um navio adversário, para aproveitar a vantagem de um ataque bem-sucedido.

12. **Como jogador**, quero encontrar presentes durante a partida e recolhê-los através de disparos, para obter armas adicionais.

13. **Como jogador**, quero utilizar diferentes tipos de mísseis, incluindo mísseis simples, grandes, chuva de mísseis e nucleares, para realizar ataques com diferentes áreas de impacto.

14. **Como jogador**, quero receber uma indicação do resultado final da partida, para saber se ganhei ou perdi, de acordo com o afundamento de toda a frota adversária.

15. **Como jogador**, quero participar em torneios diários de Battleship, para competir com outros jogadores e tentar alcançar uma boa classificação.

16. **Como organizador**, quero criar torneios privados e escolher um nome para o torneio, para organizar competições com amigos ou outros participantes.

17. **Como organizador**, quero partilhar um link de acesso ao torneio, para permitir que outros jogadores se inscrevam e participem.

18. **Como participante de um torneio**, quero consultar os torneios, os participantes, os jogos, o modo de competição e o estado do torneio, para acompanhar o seu progresso.

19. **Como jogador**, quero consultar as classificações dos torneios e os pontos obtidos, para acompanhar o meu desempenho e comparar os meus resultados com os de outros jogadores.

20. **Como jogador autenticado**, quero conversar com o meu adversário durante uma partida, para comunicar com ele em tempo real.

21. **Como jogador**, quero enviar emojis durante uma partida, para reagir às jogadas e comunicar de forma mais expressiva.

22. **Como jogador**, quero consultar o histórico das minhas partidas, para rever os jogos que realizei.

23. **Como jogador**, quero aceder à repetição de uma partida, para rever os acontecimentos e analisar as minhas jogadas.

24. **Como jogador**, quero obter moedas virtuais através da atividade na plataforma, para poder utilizá-las na loja.

25. **Como jogador**, quero utilizar moedas virtuais para adquirir avatares e emojis, para personalizar a minha experiência de jogo.
